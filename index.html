Capabilities

What the agent
can do

Lightweight, precision-engineered for local execution with zero data leakage.

01
Local Key Architecture

Links directly to Google AI Studio, OpenAI, Anthropic, or Groq. No subscriptions, no proxy servers — a direct, secure browser-to-LLM connection using your own API key.

02
Resume PDF Parser

Upload your CV once. The extension extracts name, contact info, skills, and work history into structured local storage — no re-entry needed.

03
Automated DOM Fill

Scans the live DOM of any job application page, maps form fields to your profile, and performs instant, accurate autofill actions.

04
Complete Data Sovereignty

Every parse, match, and log stays inside your Chrome container. No server ever sees your resume, credentials, or application history.

Installation

Get started in
minutes

Two paths to install — pick whatever fits your workflow.

Chrome Web Store Recommended
1
Visit the Store Page

Go to the Hunter listing in the Chrome Web Store.

2
Add to Chrome

Confirm the permission dialog. The extension registers in your toolbar instantly.

3
Configure your API Key

The setup page opens automatically. Choose your provider (Gemini, OpenAI, Anthropic, or Groq), paste your API key, and you're running instantly.

Load Unpacked Source Developer
1
Download the Build

Grab the latest ZIP from GitHub and extract it to your machine.

2
Enable Developer Mode

Open chrome://extensions/ and toggle Developer mode on.

3
Load Unpacked

Click Load unpacked and select the folder containing the build's manifest.json.

100% Private by Design

No backend servers, no telemetry, no usage tracking. Every operation runs entirely client-side inside your Chrome container, making direct requests to official AI provider APIs (Gemini, OpenAI, Anthropic, or Groq). Your resume, credentials, and applications never leave your machine.
